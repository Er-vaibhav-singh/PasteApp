# 🚀 PasteApp

PasteApp is a simple and fast web application that allows users to create, save, and manage text snippets easily. It is useful for storing notes, code snippets, and temporary text.


# Live Demo

*[![Live Demo](https://img.shields.io/badge/Live-Demo-green?style=for-the-badge&logo=vercel)](https://paste-app-afwh.vercel.app/)

## ✨ Features

* 📝 Create and save text snippets instantly  
* 📋 Copy text to clipboard in one click
* 🗂️ View and manage all saved pastes
* ⚡ Fast and responsive user interface

---

## 🛠️ Tech Stack

* React
* Tailwind CSS
* Vite
* Redux Toolkit

---

## ⚙️ Installation

Follow these steps to run the project locally:

```bash
git clone https://github.com/Er-vaibhav-singh/PasteApp.git
cd PasteApp
npm install
npm run dev
```
